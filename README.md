Entry for the [make.fun bounty "Everyday Things, Two Lines, Longer Run"](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

`main.py` writes a two-line explanation of a traffic jam to `/output/entry.txt`:
line 1 explains the everyday thing to a 10-year-old in a single vivid sentence
built on an analogy; line 2 says in one sentence why that analogy works —
what it maps and what it leaves out.

Run it with:

```sh
python3 main.py
```
